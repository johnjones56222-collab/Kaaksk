# The 1982 Crane

A first-person horror game written in C++17, compiled to WebAssembly, and played in the browser on desktop or phone.

> Thursday, November 11, 1982. 11:47 p.m.
> Harrow Marine Salvage, Berth 9, Port of Ashgrove. The union hall sent you as relief mechanic for one night: a crane that won't shut down.
> Nobody remembers the crane being rigged. It isn't on the site plan. Every night it lifts something out of the harbor, and every morning one more of the crew doesn't come in.

**Play:** open [`dist/the-1982-crane.html`](dist/the-1982-crane.html) in a current browser (Chrome, Edge, Firefox or Safari). It is one self-contained file: no install, no server, no downloads. Best with headphones, in the dark.

## What is in it

- **A full yard to explore**: guard booth, site office (front room and the foreman's office), crew room and workshop, generator shed, diesel tank, transformer cage, Pump House 2, a container maze of 40+ stacks with two open containers, the quay with three salvaged "lifts", the moored barge H-12, and Crane No. 7 itself: a climbable portal, a nine-bay lattice mast with four landings, and an operator's cab you can sit in and drive.
- **A long chain of objectives** (14 stages, about 30 tasks): find the flashlight, sign in, open the gate, find the office key, read the incident report, recover three hidden fuses, fill and fuel the generator, find a badge number to open the key cabinet, purge a flooded pump house in the right valve order, cut a lockout tag, start the brake pump, lock the slew brake, climb the crane, and decide what to do with the load still hanging on the hook.
- **Two endings**: put it back in the harbor, or land it on the quay and open it.
- **The Rigger**: a pursuer that hunts by light and sound. It patrols, investigates noises, chases, searches, and opens doors, but will not open a locker it did not see you close, will not follow you onto the barge, and stops at the foot of the crane. Six hiding lockers across the yard.
- **16 documents and 6 tapes** that tell what happened to the crew, plus 8 battery packs (the flashlight drains).
- **Scripted scares**: the crane moving with nobody in the cab, a figure on a container stack in a lightning flash, five men in the maze who are four metres nearer every flash, knocking from inside a container (don't knock back), a phone that rings, a terminal that switches itself on, a door from the harbor that opens by itself, something on the mast ladder below you, and the man in the cab who waves if you stare at him.
- **Checkpoints** at every objective (saved in the browser), three difficulties, a journal with objectives, a pan/zoom yard map, documents, tapes and inventory.

Everything is generated by the C++ code at load time: there are **no image, model or sound files**. 44 materials and around 100 signs, posters and decals are painted procedurally (`src/texgen.cpp`); every building and prop is built from code (`src/level*.cpp`); every sound, from footsteps on eight surfaces to thunder, the generator, a valve radio playing a waltz and the end theme, is synthesised (`src/audio.cpp`).

## Controls

| | Keyboard and mouse | Touch screen |
|---|---|---|
| Move | W A S D | drag on the left half |
| Look | mouse (click to capture it) | drag on the right half |
| Use / pick up / open | E or left click | USE button, or tap the object |
| Flashlight | F | LAMP |
| Run / crouch | Shift / C | RUN / LOW |
| Journal and map | Tab | LOG |
| Pause | Esc | II |
| Crane cab | A D slew, W S trolley, R F hoist, Space release, Q let go | SLEW, TROLLEY and HOIST levers, RELEASE, X |

If the browser does not allow mouse capture (some embedded pages), hold the left button and drag to look.

## Assist

Four optional aids, each toggled with the number keys while playing, or from **Pause > Assist** (and Settings) on any device. Choices are remembered.

| Key | Assist | What it does |
|---|---|---|
| 1 | Full bright | Lights everything evenly, thins the fog, lifts the vignette |
| 2 | Monster ESP | Draws the Rigger through walls in a colour for its state, its planned route on the ground, and a panel with what it is doing (dormant, patrolling, investigating a noise, hunting, searching, watching), how far away it is, whether it can see you right now, its alertness, how far it can see you at this moment and why (flashlight, lamps, darkness, crouching), and how far your last sound carried |
| 3 | Mission ESP | Marks where the current objective needs you next, with distance; off-screen targets get an arrow at the edge of the screen |
| 4 | Item ESP | Marks pickups, batteries, tapes, unread documents and nearby hiding lockers |

The ESP readout uses the same sight and hearing numbers the Rigger's AI uses.

## Mobile

The game detects touch screens and switches to on-screen controls, lower graphics settings and a reduced render resolution that adapts to the frame rate. It runs in portrait or landscape (landscape is better). Settings let you change look speed, graphics quality, resolution, brightness, volume, text size and head bob.

## Building

Requirements: [Emscripten](https://emscripten.org) (built and tested with 7.0.0) for the game, and g++ for the native test tools.

```sh
./build_web.sh            # release: dist/the-1982-crane.html (single file)
./build_web.sh debug      # build-debug/index.html + .js + .wasm, assertions on
./build_web.sh artifact   # one page carrying the WebAssembly build and a pure-JavaScript
                          # fallback, for hosts that refuse to compile WebAssembly
```

## Tests

```sh
tests/build_native.sh build-native     # native builds with AddressSanitizer + UBSan
build-native/headless all              # a bot plays the whole game: both endings,
                                       # plus live-AI runs on standard and nightmare
build-native/worldmap map.ppm          # reachability of every item, note and objective

# browser tests (Playwright + headless Chromium), against a served debug build
node tests/desktop_test.cjs http://localhost:8765/index.html out/
node tests/mobile_test.cjs  http://localhost:8765/index.html out/
node tests/browser_test.cjs http://localhost:8765/index.html out/ basic
node tests/assist_test.cjs  http://localhost:8765/index.html out/
```

The headless bot drives the game through the same `Controls` interface the player uses, with real collision, navigation, AI, crane physics and the audio mixer running, and checks that every checkpoint survives a save and reload. The browser tests use real keyboard, mouse and touch events.

## Source layout

| File | What it does |
|---|---|
| `src/core.h` | vectors, matrices, boxes, random numbers |
| `src/texgen.*` | procedural textures, signs and decals |
| `src/world.*`, `src/builder.h` | world data, collision queries, navigation grid and A*, mesh building |
| `src/level*.cpp` | the yard, the buildings, containers, quay, barge, the crane, the Rigger |
| `src/game.*` | player, interaction, objectives, checkpoints |
| `src/game_events.cpp` | scripted events, weather, lights, ambience |
| `src/game_crane.cpp` | crane simulation (slew, trolley, hoist, swinging load) and the endings |
| `src/rigger.cpp` | the Rigger's perception, pursuit and stop-motion animation |
| `src/story.cpp` | every document, tape and ending card |
| `src/audio.*` | synthesised sound, 3D mixer, weather and dread beds, reverb |
| `src/render.*`, `src/gfx.h` | WebGL 2 renderer: lights, flashlight shadow, fog, rain, wet surfaces, film and tape post effects |
| `src/ui.*` | input mapping, HUD, touch controls, menus, journal, map, endings |
| `src/main.cpp` | browser entry point: context, events, Web Audio, storage, main loop |

The 1982 Crane is an original game; its story, characters and setting are fictional.
